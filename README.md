# Knowledge Base

本地文件内容搜索系统：对多个目录递归建全文索引（Lucene + Tika），支持中文分词、高亮摘要、文件预览与增量更新。

## 环境要求

- JDK 17+
- Maven 3.6+

## 编译运行

构建（Maven 未加 PATH 时用本机实际路径，下面已写好）：

```bash
mvn -DskipTests clean package
java -jar target/knowledge-base-0.1.0.jar
```

或者直接双击 `build.bat` 构建，再运行 `start.bat` 启动（`start.bat` 可在任意目录运行）。

浏览器访问 http://127.0.0.1:8080

## 使用说明

1. **库管理**：新建索引库（相当于工作区），为其添加要索引的目录绝对路径，自动递归扫描建索引；支持重扫、移除、重建索引。
2. **搜索**：输入关键词搜索，支持选择库范围、按文件类型（如 `pdf,docx`）和修改时间过滤；点击结果可在页内预览（PDF/图片直接渲染，Office 文档显示抽取的纯文本）。
3. **设置**：
   - 索引存储位置：更换时要求新目录为空，已有索引自动迁移
   - 服务端口：保存到 `data/app.properties`，重启后生效
   - 中文分词器：SmartChinese / IK 可切换，切换后建议重建索引
   - 每页结果数量、默认库记忆

文件增删改会被自动监听并增量更新索引（约 1.5 秒防抖），无需手动重扫；服务重启时也会自动比对补漏。

## 数据目录

所有数据默认存放在运行目录下 `./data/`：

| 路径 | 内容 |
|------|------|
| `data/kb-meta*` | H2 元数据库（库/目录/设置） |
| `data/indexes/` | Lucene 索引（可在设置中迁移） |
| `data/app.properties` | 应用配置（端口等） |

仅监听 `127.0.0.1`，不对外网开放。
